# Presentación Week10 — Plantilla / Borrador

Este archivo es un borrador en Markdown para la presentación de la Semana 10. Cuando tengas la presentación final, súbela como `PresentationWeek10.pptx` o `PresentationWeek10.pdf`.

Diapositivas sugeridas:
- Título y equipo
- Resumen ejecutivo
- Objetivos del prototipo
- Arquitectura del sistema (diagrama)
- Flujo de datos y artefactos (datasets, modelos)
- Demo (capturas o enlace a video)
- Resultados principales
- Limitaciones y riesgos
- Próximos pasos
