# Código del prototipo (deliveries/week10/code)

Coloca aquí todo el código fuente que conforma el prototipo. Estructura recomendada:

code/
├── app.py               # entrypoint para la demo (Flask / Streamlit u otro)
├── requirements.txt     # dependencias específicas del prototipo
├── inference.py         # funciones de carga de modelo y predicción
├── utils.py             # utilidades auxiliares
└── notebooks/           # notebooks relevantes para reproducibilidad

Archivo de ejemplo incluido (script de prueba): `../prueba.py`

Cómo ejecutar (ejemplo si usas Python):

```bash
# instalar dependencias del prototipo (si existe code/requirements.txt)
pip install -r deliveries/week10/code/requirements.txt

# ejecutar la app
python deliveries/week10/code/app.py
```
